# 🤖 Generative AI Chatbot

A chatbot built using NLP, Sentence Transformers, Retrieval-Augmented Generation (RAG), and Hugging Face Transformers.

## Features

- NLP Text Preprocessing
- Semantic Search
- Cosine Similarity
- RAG-based Response Generation
- Interactive Chatbot

## Technologies

- Python
- Pandas
- NLTK
- Sentence Transformers
- Hugging Face Transformers
- Scikit-learn

## Project Structure

```
├── chatbot.ipynb
├── ChatBot_Dataset.csv
├── requirements.txt
└── README.md
```

## How to Run

1. Open `chatbot.ipynb` in Google Colab.
2. Install the required libraries.
3. Upload the dataset if needed.
4. Run all cells.
5. Start chatting with the bot.
